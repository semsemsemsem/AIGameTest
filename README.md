# Neon Dash

A small cyber/neon pixel-art endless runner that runs in the browser. All art is hand-made pixel sprites defined in `js/sprites.js`.

## Play

Open `index.html` in a web browser. No build step or server is needed.

## Controls

| Key | Action |
|---|---|
| Space / Up / W | Jump (hold for a higher jump) |
| Down / S | Duck (fast-fall while in the air) |
| P | Pause |
| M | Mute |
| Space / Enter | Start / retry |

Jump over firewalls, duck under low drones, and grab data chips for +50 points. The game speeds up the longer you survive. Your high score is saved in the browser.
